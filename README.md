
# 💰 Bank Loan Analysis System

## 📌 Overview
The **Bank Loan Analysis System** analyzes loan approvals, financial risks, and customer credit behavior to support better lending decisions through data-driven insights.

## 🎯 Business Problem
Banks need to evaluate loan approvals, identify default risks, and analyze customer financial profiles to reduce losses and improve decision-making.

## 🛠️ Tools Used
- **SQL** – Data Analysis  
- **Power BI** – Dashboard & Visualization  
- **Excel** – Data Cleaning  
- **Python** – Data Processing & Analysis  

## ✨ Key Features
- Loan Approval Analysis  
- Default Risk Analysis  
- Income Analysis  
- Credit Analysis  
- Risk Dashboard  

## 📚 Skills Learned
- Advanced SQL  
- Financial Analytics  
- Data Modeling  
- KPI Dashboards  
- Risk Analysis
